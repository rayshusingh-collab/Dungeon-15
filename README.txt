Dungeon15 prototype for Godot 4.x

OPEN:
1. Extract Dungeon15.zip
2. Open Godot Project Manager
3. Import project.godot from the Dungeon15 folder
4. Press F6/F5

CONTROLS:
- Mouse/touch joystick at bottom-left
- Arrow keys also move for desktop testing
- SPACE attacks enemies near the player

CURRENT PROTOTYPE:
- Player movement
- Smooth mouse/touch joystick
- Collision walls
- Seeded enemy placement
- Enemy chase behavior
- Melee attack
- Enemy HP/death
- Door changes from red to green after all enemies die

This is the clean foundation, not the finished commercial game yet.
